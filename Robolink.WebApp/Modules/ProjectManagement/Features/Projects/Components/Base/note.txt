Câu hỏi của em **rất đúng hướng kiến trúc component** 👍
4 cái `Base` này thực ra là **design pattern rất phổ biến trong Blazor UI libraries** (MudBlazor, Radzen, AntDesign Blazor đều làm vậy).

Mục tiêu:

```
Base = xử lý logic chung
Composite / Feature component = UI cụ thể
```

Tức là:

```
AppInputBase  -> TextInput / Select / DatePicker
AppFieldBase  -> Label + Validation wrapper
AppButtonBase -> Button variants
AppLayoutBase -> Layout wrapper
```

Anh sẽ giải thích **3 thứ cho từng Base**:

1️⃣ Code cơ bản
2️⃣ Nó giải quyết vấn đề gì
3️⃣ Component nào sẽ dùng lại nó

---

# 1️⃣ AppFieldBase

## 🎯 Mục đích

Wrapper cho **form field**.

Giải quyết các thứ:

```
Label
Validation message
Required mark
Help text
Layout
```

Giống như:

```
<label>
<input>
<span validation>
```

---

## Code

```csharp
using Microsoft.AspNetCore.Components;

namespace Components.Base;

public class AppFieldBase : ComponentBase
{
    [Parameter] public string? Label { get; set; }

    [Parameter] public string? For { get; set; }

    [Parameter] public string? Error { get; set; }

    [Parameter] public bool Required { get; set; }

    [Parameter] public RenderFragment? ChildContent { get; set; }
}
```

---

## Razor

```razor
<div class="app-field">

    @if (!string.IsNullOrEmpty(Label))
    {
        <label class="form-label" for="@For">
            @Label
            @if (Required)
            {
                <span class="text-danger">*</span>
            }
        </label>
    }

    <div class="app-field-control">
        @ChildContent
    </div>

    @if (!string.IsNullOrEmpty(Error))
    {
        <div class="text-danger small">
            @Error
        </div>
    }

</div>
```

---

## Component sử dụng

```
AppTextInput
AppSelect
AppDatePicker
AppCheckbox
```

Ví dụ:

```razor
<AppFieldBase Label="Project Name" Required="true">

    <AppTextInput @bind-Value="Model.Name" />

</AppFieldBase>
```

# 2️⃣ AppInputBase

## 🎯 Mục đích

Đây là **base class cho mọi input**.

Giải quyết:

```
Two-way binding
ValueChanged
Validation
Id
Disabled
Placeholder
```

---

## Code

```csharp
using Microsoft.AspNetCore.Components;
using Microsoft.AspNetCore.Components.Forms;

namespace Components.Base;

public abstract class AppInputBase<T> : InputBase<T>
{
    [Parameter] public string? Id { get; set; }

    [Parameter] public string? Placeholder { get; set; }

    [Parameter] public bool Disabled { get; set; }

    [Parameter] public string CssClass { get; set; } = "form-control";

    protected string InputCssClass
        => $"{CssClass} {(EditContext?.GetValidationMessages(FieldIdentifier).Any() == true ? "is-invalid" : "")}";
}
```

---

## Nó làm gì?

Kế thừa:

```
InputBase<T>
```

=> Blazor sẽ tự xử lý:

```
EditContext
Validation
Bind-Value
FieldIdentifier
```

---

## Component sử dụng

```
AppTextInput
AppSelect
AppNumberInput
AppDatePicker
AppCheckbox
```

# 3️⃣ AppButtonBase

## 🎯 Mục đích

Standard hóa button.

Giải quyết:

```
Loading state
Disabled
Variants
Icon
Click handling
```

---

## Code

```csharp
using Microsoft.AspNetCore.Components;

namespace Components.Base;

public class AppButtonBase : ComponentBase
{
    [Parameter] public string Variant { get; set; } = "primary";

    [Parameter] public bool Disabled { get; set; }

    [Parameter] public bool Loading { get; set; }

    [Parameter] public EventCallback OnClick { get; set; }

    [Parameter] public RenderFragment? ChildContent { get; set; }
}
```

---

## Razor

```razor
<button class="btn btn-@Variant"
        disabled="@Disabled"
        @onclick="HandleClick">

    @if (Loading)
    {
        <span class="spinner-border spinner-border-sm"></span>
    }
    else
    {
        @ChildContent
    }

</button>

@code {

    private async Task HandleClick()
    {
        if (!Loading)
        {
            await OnClick.InvokeAsync();
        }
    }

}
```

---

## Component sử dụng

```
AppButton
AppSubmitButton
AppIconButton
```

# 4️⃣ AppLayoutBase

## 🎯 Mục đích

Wrapper cho layout blocks.

Giải quyết:

```
Spacing
Container
Consistent layout
```

---

## Code

```csharp
using Microsoft.AspNetCore.Components;

namespace Components.Base;

public class AppLayoutBase : ComponentBase
{
    [Parameter] public string CssClass { get; set; } = "";

    [Parameter] public RenderFragment? ChildContent { get; set; }
}
```

---

## Razor

```razor
<div class="@CssClass">

    @ChildContent

</div>
```

# 🚀 Lợi ích thật sự (Senior dev reason)

Nếu không có Base:

```
TextInput
Select
DatePicker
Checkbox
```

Mỗi component phải viết lại:

```
Validation
Disabled
Css
Error
Label
```

=> code **trùng lặp khủng khiếp**

---

Có Base:

```
Validation: 1 nơi
Styling: 1 nơi
Binding: 1 nơi
```

=> maintain dễ.

---

# ⭐ Quan trọng nhất

Cái **thực sự đáng giá nhất** là:

```
AppInputBase<T> : InputBase<T>
```

Vì nó integrate với:

```
EditForm
Validation
DataAnnotations
FluentValidation
```
